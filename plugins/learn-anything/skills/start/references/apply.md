# Apply

Human mode, optional: one small, real task that makes the learner use what they have drilled.

**Propose one task** that takes 15–45 minutes and exercises two or three mental models, and name them. Prefer models that are Solid or nearly so, plus one Shaky one. Describe the goal, the deliverable, and how the learner will know it works, and let them adjust it or ask for another before starting.

- Programming domain: runnable code with a quick check, such as a test or a command whose output shows it works.
- Other domains: a concrete deliverable, such as a one-page plan, a decision with its trade-offs, a diagram, or a critique of a real example.

When an existing practice tool fits better and is available, offer it instead: an exercise from a langlings course for the language (the langlings skill), or an Exercism exercise or algorithm problem (the algorithm-learning skill).

Keep task files in `.learning/<slug>/apply/<task-name>/` unless the learner wants them elsewhere.

**Keep the learner as the author.** Do not produce the deliverable for them. When they are stuck, point to the mental model that applies before suggesting a step.

**Review it conversationally.** For code, run the check first and report its actual result. Then say what worked, which mental model shows up where, and one thing to change. No grade.

**Update `state.md`.** A model the learner applied correctly counts as a correct recall; one they misapplied goes to Shaky with a note. Add a session-log line naming the task.
