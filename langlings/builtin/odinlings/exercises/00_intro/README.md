# Intro

Every Odin program starts in `package main` at `main :: proc()`. Printing
lives in the `core:fmt` package, which you have to import yourself:
`fmt.println`, `fmt.printf`, `fmt.printfln` and friends.

Each exercise here is a single file. The runner compiles it with
`odin run <file> -file` (or `odin test <file> -file`), so read the compiler
errors carefully: Odin's are short and usually say exactly what is wrong.
